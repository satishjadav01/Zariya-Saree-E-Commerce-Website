# ✨ Zariya – Traditional Saree E-Commerce Platform

Zariya is a modern and elegant Saree E-Commerce Platform designed to bring traditional Indian fashion to the digital world.

The project focuses on providing a smooth and user-friendly shopping experience where customers can explore saree collections, discover beautiful designs, and enjoy a modern online shopping interface.

## 🌟 Project Features

- **Modern UI/UX** – Elegant and user-friendly shopping interface.
- **Saree Collections** – Showcase traditional and designer sarees.
- **Product Discovery** – Explore available products and collections.
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- **Database Integration** – Database configuration using Drizzle ORM.
- **Backend Integration** – Supabase integration.
- **Reusable Components** – Organized component-based architecture.
- **Code Quality** – ESLint configuration.
- **Testing Setup** – Vitest configuration.

## 🛠️ Technology Stack

- TypeScript
- Vite
- Bun
- Supabase
- Drizzle ORM
- Vitest
- ESLint

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- [Bun](https://bun.sh/)
- [Git](https://git-scm.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/satishjadav01/zariya-saree-project.git
```

### 2. Navigate to the Project

```bash
cd zariya-saree-project
```

### 3. Install Dependencies

```bash
bun install
```

### 4. Configure Environment Variables

Create or configure your `.env` file with the required Supabase and database credentials.

**Important:** Never upload private API keys, database passwords, or secret environment variables to GitHub.

### 5. Start Development Server

```bash
bun run dev
```

Open the local development URL displayed in your terminal.

### 6. Build for Production

```bash
bun run build
```

## 🧪 Testing

Run the configured test script if available:

bun run test
